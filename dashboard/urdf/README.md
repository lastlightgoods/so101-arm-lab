# SO-101 URDF and meshes

`so101.urdf` and the STL files under `assets/` are the SO-ARM101 follower model from
[TheRobotStudio/SO-ARM100](https://github.com/TheRobotStudio/SO-ARM100) (Apache-2.0), exported with
onshape-to-robot. They are redistributed here unchanged so the wall dashboard can draw the arm; the MIT
licence of this repository does not apply to them, their upstream licence does.
